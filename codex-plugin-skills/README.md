# Codex Plugin Skills

이 디렉터리는 현재 Codex plugin cache에서 노출된 스킬의 참고용 스냅샷이다.

plugin cache 스킬은 일반적으로 plugin 설치/업데이트 과정에서 관리되므로 `setup.sh`로 자동 배포하지 않는다.
다른 컴퓨터에서 동일 plugin을 설치할 수 없는 경우에만 이 디렉터리의 내용을 참고해 수동 복구한다.

## 포함 범위

- Browser Use
- Figma
- Frontend Design
- GitHub
- Gmail
- Notion
- Test Android Apps
- Documents
- Presentations
- Spreadsheets

각 plugin 하위에는 해당 plugin이 제공한 `skills/*` 디렉터리를 그대로 보관한다.
